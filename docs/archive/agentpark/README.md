# Archive: documents from the agentpark repository

Mycelos started in the `stefan-kp/agentpark` repository (under the working
names AgentOS and Maicel) and moved to `mycelos-ai/mycelos` with a fresh
history in April 2026. These documents existed only in agentpark and are
kept here so the old repository can be archived or deleted.

They are historical. Names, paths and decisions in them may be out of date;
the code and `docs/superpowers/` at the top level describe the current state.

| Folder / file | Content |
|---|---|
| `superpowers/specs/` | Original design specs, including the full system spec `2026-03-15-agentos-design.md` |
| `superpowers/plans/` | Implementation plans from March and April 2026 |
| `superpowers/research/` | Early research notes |
| `reviews/` | Architecture, security and code audits (March 2026) |
| `designs/` | Connector setup UX and rich web components |
| `constitution.md` | Original constitution document |
| `go-live-beta-plan.md`, `launch-readiness-2026-04-07.md` | Beta launch planning |
| `openclaw-*`, `deerflow-*`, `maicel-vs-openclaw-*`, `analysis/` | Comparisons with other agent frameworks |

Some of the comparison notes (for example `Top use cases.md`) are written in
German; they are kept unchanged as historical source material.
